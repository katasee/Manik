# Custom Tab Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the floating custom tab bar (dark capsule, white circle behind the active icon,
optional red badge) and wire it into both `MasterRootView` (3 tabs) and `ClientRootView` (2 tabs).

**Architecture:** No generic protocol. Two concrete `enum`s (`MasterTab`, `ClientTab`), each in its
own file, plug into a single non-generic `CustomTabBar` view via a `CabinetKind` enum
(`.master(selection:badge:)` / `.client(selection:)`) that carries the `Binding` to the caller's
selected-tab state. `TabBarButton` renders one tab (icon, active white-circle background, badge)
and is reused by both cabinets. Placeholder content in `MasterRootView`/`ClientRootView` switches
visibly by tab so the wiring is observable, but the real per-tab screens (Schedule, Requests,
Stats, Booking, My Bookings) are out of scope — later plan items.

**Tech Stack:** SwiftUI (iOS 17.2 deployment target, per project `CLAUDE.md` — do not reach for
iOS 18/26-only APIs), SF Symbols, Swift 6.1 tools.

## Global Constraints

- Deployment target is iOS 17.2 (`CLAUDE.md`) — this overrides any general "iOS 26 default"
  guidance; stick to APIs available at 17.2 (`matchedGeometryEffect`, `@Namespace`,
  `@Previewable @State` in `#Preview` are all fine — `@Previewable` is a preview-only macro, not
  gated by the app's deployment target).
- No `ObservableObject`/`@Published`, no singletons of our own — not needed here (`CustomTabBar`
  is stateless, driven entirely by bindings passed in).
- Text never uses the system font — always `Font.elmsSans(_:_:)`.
- User-facing / VoiceOver strings never sit as bare literals — they go in
  `Manik/Manik/Localizable/Localizable.xcstrings` under a `feature.kind.name` key and get pulled
  in via a `LocalizedStringKey`-typed property (see `Manik/Manik/Auth/AuthFieldView.swift` for the
  established pattern: `Text(label)` where `label: LocalizedStringKey`).
- Colors go through semantic `Assets.xcassets` entries (`Color.xxx`, auto-generated by Xcode from
  the colorset name) — never `Color(red:green:blue:)`. Plain SwiftUI `.white`/`.black` are fine for
  incidental foreground text/tint (already used in `AuthView.swift:97,110`), but a color that
  defines a reusable piece of chrome (the capsule background, the active circle) gets its own
  named asset.
- Any function/initializer call with 3+ arguments: one argument per line.
- No test target exists (`CLAUDE.md`) — verification is `xcodebuild build` plus manual inspection
  of `#Preview`s (previews construct views directly with stub data, bypassing Firebase/Auth, so
  they're the practical way to eyeball this against the reference screenshot).
- Build command: `cd Manik && xcodebuild -scheme Manik -destination 'generic/platform=iOS Simulator' build`

- [ ] **Step 4: Create `TabBarMetrics.swift`**

`Manik/Manik/TabBar/TabBarMetrics.swift`:

```swift
import SwiftUI

enum TabBarMetrics {
    enum Size {
        static let capsuleHeight: CGFloat = 56
        static let activeCircleDiameter: CGFloat = 64
        static let activeCircleLift: CGFloat = 18
        static let iconSize: CGFloat = 22
        static let badgeDiameter: CGFloat = 18
        /// Apple's HIG minimum tap target; `activeCircleDiameter` (64) already exceeds this,
        /// so every `TabBarButton` — active or not — clears it without a separate frame call.
        static let minTapArea: CGFloat = 44
    }

    enum Spacing {
        static let tabSpacing: CGFloat = 4
        static let innerHorizontalPadding: CGFloat = 12
        static let capsuleHorizontalPadding: CGFloat = 24
        static let bottomInset: CGFloat = 12
    }

    enum Opacity {
        static let inactiveIcon: Double = 0.55
    }

    enum AnimationStyle {
        static let selection = Animation.spring(response: 0.35, dampingFraction: 0.75)
    }
}
```

- [ ] **Step 2: Create `TabBarButton.swift`**

`Manik/Manik/TabBar/TabBarButton.swift`:

```swift
import SwiftUI

struct TabBarButton: View {
    let systemImage: String
    let titleKey: LocalizedStringKey
    let isActive: Bool
    let badge: Int?
    let namespace: Namespace.ID
    let action: () -> Void

    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    var body: some View {
        Button(titleKey, systemImage: systemImage, action: action)
            .labelStyle(.iconOnly)
            .font(.system(size: TabBarMetrics.Size.iconSize, weight: .medium))
            .foregroundStyle(iconColor)
            .frame(width: TabBarMetrics.Size.activeCircleDiameter, height: TabBarMetrics.Size.activeCircleDiameter)
            .background(activeBackground)
            .offset(y: liftOffset)
            .overlay(alignment: .topTrailing) {
                if let badge {
                    TabBarBadge(count: badge)
                        .offset(x: 4, y: -4)
                }
            }
            .animation(TabBarMetrics.AnimationStyle.selection, value: isActive)
            .accessibilityAddTraits(isActive ? [.isSelected] : [])
    }

    @ViewBuilder
    private var activeBackground: some View {
        if reduceMotion {
            Circle()
                .fill(Color.tabBarActiveBackground)
                .opacity(isActive ? 1 : 0)
        } else if isActive {
            Circle()
                .fill(Color.tabBarActiveBackground)
                .matchedGeometryEffect(id: "activeTabCircle", in: namespace)
        }
    }

    private var iconColor: Color {
        isActive ? Color.textPrimary : Color.tabBarActiveBackground.opacity(TabBarMetrics.Opacity.inactiveIcon)
    }

    private var liftOffset: CGFloat {
        (isActive && !reduceMotion) ? -TabBarMetrics.Size.activeCircleLift : 0
    }
}

#Preview {
    @Previewable @Namespace var namespace

    HStack(spacing: TabBarMetrics.Spacing.tabSpacing) {
        TabBarButton(
            systemImage: "calendar",
            titleKey: "tabBar.tab.schedule",
            isActive: false,
            badge: nil,
            namespace: namespace,
            action: {}
        )
        TabBarButton(
            systemImage: "bell",
            titleKey: "tabBar.tab.requests",
            isActive: false,
            badge: 2,
            namespace: namespace,
            action: {}
        )
        TabBarButton(
            systemImage: "slider.horizontal.3",
            titleKey: "tabBar.tab.stats",
            isActive: true,
            badge: nil,
            namespace: namespace,
            action: {}
        )
    }
    .padding(.horizontal, TabBarMetrics.Spacing.innerHorizontalPadding)
    .frame(height: TabBarMetrics.Size.capsuleHeight)
    .background(Color.tabBarBackground, in: .capsule)
    .padding()
}
```

`Manik/Manik/TabBar/CustomTabBar.swift`:

```swift
import SwiftUI

struct CustomTabBar: View {
    let kind: CabinetKind

    @Namespace private var tabBarNamespace

    var body: some View {
        Group {
            switch kind {
            case .master(let selection, let badge):
                HStack(spacing: TabBarMetrics.Spacing.tabSpacing) {
                    ForEach(MasterTab.allCases) { tab in
                        TabBarButton(
                            systemImage: tab.systemImage,
                            titleKey: tab.titleKey,
                            isActive: tab == selection.wrappedValue,
                            badge: badge(tab),
                            namespace: tabBarNamespace,
                            action: { selection.wrappedValue = tab }
                        )
                    }
                }
            case .client(let selection):
                HStack(spacing: TabBarMetrics.Spacing.tabSpacing) {
                    ForEach(ClientTab.allCases) { tab in
                        TabBarButton(
                            systemImage: tab.systemImage,
                            titleKey: tab.titleKey,
                            isActive: tab == selection.wrappedValue,
                            badge: nil,
                            namespace: tabBarNamespace,
                            action: { selection.wrappedValue = tab }
                        )
                    }
                }
            }
        }
        .padding(.horizontal, TabBarMetrics.Spacing.innerHorizontalPadding)
        .frame(height: TabBarMetrics.Size.capsuleHeight)
        .background(Color.tabBarBackground, in: .capsule)
        .padding(.horizontal, TabBarMetrics.Size.capsuleHorizontalPadding)
        .padding(.bottom, TabBarMetrics.Spacing.bottomInset)
    }
}

#Preview("Master — 3 tabs") {

    ZStack(alignment: .bottom) {
        Color.background.ignoresSafeArea()
        CustomTabBar(kind: .master(selection: $selection, badge: { $0 == .requests ? 2 : nil }))
    }
}

#Preview("Client — 2 tabs") {
    @Previewable @State var selection: ClientTab = .booking

    ZStack(alignment: .bottom) {
        Color.background.ignoresSafeArea()
        CustomTabBar(kind: .client(selection: $selection))
    }
}
```
